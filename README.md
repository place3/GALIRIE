# GALIRIE — Telegram-бот

Python-бот для подачи объявлений о продаже одежды и их модерации перед публикацией в канале. Реализация использует aiogram 2.x, FSM и хранение состояния в памяти.

## Возможности в коде

- Форма объявления с описанием, ценой и фотографиями.
- Отправка материалов администратору для модерации.
- Подтверждение или отклонение публикации через inline-кнопки.
- FAQ и инструкции для пользователя.

## Структура

- `main.py` — обработчики, состояния диалога и публикация.
- `templ/` — локальные фотографии объявлений; в Git не включаются.

## Настройка

Код рассчитан на API aiogram 2.x и не совместим с aiogram 3 без адаптации. Полный запуск в свежем окружении пока не проверен.

Перед запуском задайте переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен бота, выданный BotFather |
| `CHANNEL_USERNAME` | Идентификатор канала для публикации |
| `ADMIN_ID` | Идентификатор администратора |

Имена переменных перечислены в `.env.example`. Программа читает окружение через `os.environ`; `.env` автоматически не загружается. После настройки окружения точка входа — `python main.py`.

## Состояние проекта

Это ранний проект на Python. Тесты, CI, постоянное хранилище состояний и автоматизированное развёртывание пока не добавлены. Для перезапуска процесса состояния FSM не сохраняются.

Токен вынесен из исходного кода в переменную окружения. Если ранее опубликованный токен ещё действителен, его необходимо отозвать через BotFather: изменение текущего файла не удаляет значение из истории Git.

## Известные ограничения

- Данные объявления хранятся в глобальных переменных: параллельные диалоги пользователей могут мешать друг другу.
- В обработчике подтверждения есть опечатка `tate.finish()`; в другом месте `state.finish()` вызывается без `await`.
- Пути фотографий используют разделители Windows; переносимость не проверена.
- Обработчик модерации не проверяет идентификатор администратора. До исправления авторизации бот не предназначен для публичного запуска.

Фотографии старых объявлений и настройки IDE исключены из текущей ветки. Локальные копии сохранены; история Git не переписывалась.
